 Using Docker Compose Example 
Here’s an example of a docker-compose.yml file for a simple React app with 
a backend: 
 
File: docker-compose.yml 
 
version: '3' 
services: 
  frontend: 
    image: my-react-app 
    ports: 
      - "3000:3000" 
    networks: 
 
      - my-network 
  backend: 
    image: my-backend 
    ports: 
      - "5000:5000" 
    networks: 
      - my-network 
networks: 
  my-network: 
 
 
To start the application: 
 
docker-compose up 
 
 
To shut it down: 
 
docker-compose down
